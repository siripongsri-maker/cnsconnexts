# Phase 2: ใช้งานจริง — ย้ายขึ้นฐานข้อมูลกลาง + ปรับ UX ตามคอมเมนต์

## 1. เอา Demo ออกทั้งหมด
- ลบชุดข้อมูลตัวอย่างทั้งหมด (ผู้ใช้ 20 คน, ไอเดีย, การเชื่อมต่อ, คำมั่นสัญญา, ผลงาน, โน้ตรายจังหวัด)
- ลบการ "จำลองการตอบรับอัตโนมัติ" และ "ข้อความตอบกลับอัตโนมัติ" ในแชท — Phase 2 ต้องเป็นคนจริงตอบคนจริง
- ทุกหน้าที่เคยพึ่งเดโม่ จะมี Empty State ภาษาไทยที่บอกว่าให้ทำอะไรต่อ (เช่น "ยังไม่มีใครในระบบ ชวนเพื่อนสแกน QR เพื่อเริ่ม")

## 2. ย้ายข้อมูลขึ้นฐานข้อมูลกลาง (Lovable Cloud)
สร้างตารางกลางเพื่อให้ข้อมูลซิงก์ข้ามเครื่องและหลังบ้านเห็นของจริง:

| ตาราง | เก็บอะไร |
| --- | --- |
| `participants` | โปรไฟล์พลัง: ชื่อ จังหวัด ภาค องค์กร เจน bio ประเด็น พลังที่มี/ที่ต้องการ รูป ช่องทางเข้า |
| `ideas` | ไอเดียในตลาดนัด |
| `connections` | คู่ที่เชื่อมกัน + คะแนน + เหตุผล + สถานะ |
| `commitments` | ก้าวต่อไป วันนัด สถานะ RSVP |
| `messages` | แชทของแต่ละคู่ |
| `submissions` | ผลงานสำหรับ e-book |
| `province_notes` | ข้อมูลรายจังหวัดบนแผนที่ |

หลักการเข้าถึง:
- ผู้เข้าร่วมทุกคน (รวมโหมดไม่ล็อกอินผ่าน QR) อ่านโปรไฟล์/ไอเดีย/ผลงาน/โน้ตจังหวัดได้ เพื่อให้จับคู่ได้
- แก้ไข/ลบ ได้เฉพาะข้อมูลของตัวเอง
- แชทอ่านได้เฉพาะคู่ของตัวเอง
- หลังบ้าน `/admin` อ่าน/แก้ทั้งหมดได้

การเชื่อมต่อฝั่งแอป: `src/lib/store.ts` จะเปลี่ยนจากอ่าน/เขียน localStorage เป็นอ่าน/เขียนฐานข้อมูลกลาง โดยคง API เดิม (`saveProfile`, `connect`, `addCommitment`, …) ทุกตัว หน้าจอทั้งหมดจึงไม่ต้องแก้ พร้อมเปิด realtime ให้แดชบอร์ดสดและแชทอัปเดตทันทีระหว่างเครื่อง

โปรไฟล์เดิมที่อยู่ในเครื่องผู้ใช้จะถูก upload ขึ้นฐานข้อมูลอัตโนมัติครั้งแรกที่เปิดแอป เพื่อไม่ให้ผู้ทดลองใช้รอบแรกข้อมูลหาย

## 3. โลโก้ผู้สนับสนุนหลัก (สช.)
- อัปโหลดโลโก้ สช. เป็นแอสเซต แล้ววางเป็นแถบ "สนับสนุนโดย" ที่ด้านล่างของหน้าแรกและใน App Shell ทุกหน้า
- เอาป้าย "สมัชชาสุขภาพแห่งชาติ" ด้านบนหน้าแรกออก

## 4. ปรับตามคอมเมนต์ผู้ทดลองใช้
**คอมเมนต์ 1 — ต้องมี User Guide ก่อนเริ่ม**
- เพิ่มหน้าจอ "แนะนำก่อนเริ่ม" 3 การ์ด อ่านไม่เกิน 20 วินาที: แอปนี้มีไว้ทำอะไร · จะได้อะไรกลับไป · 3 ขั้นตอนที่ต้องทำ (สร้างโปรไฟล์พลัง → เลือกคนที่ใช่ → นัดก้าวต่อไป)
- แสดงก่อนเข้า onboarding และกดเปิดซ้ำได้จากเมนู
- เพิ่มหน้า `/guide` คู่มือฉบับเต็ม ตัวอักษรใหญ่ อ่านง่ายสำหรับทุกช่วงวัย พร้อมคำถามพบบ่อย

**คอมเมนต์ 2 และ 3 — งงเรื่องปัดซ้าย/ปัดขวา**
- ใส่ Coach mark ครั้งแรกในหน้า Discover: การ์ดขยับให้เห็น พร้อมป้าย "ปัดขวา = สนใจ" / "ปัดซ้าย = ข้าม"
- เพิ่มปุ่มใหญ่ชัดเจนใต้การ์ด (ข้าม / สนใจ / เชื่อมเลย) เพื่อให้ไม่ต้องปัดก็ใช้ได้
- เพิ่มสวิตช์ "โหมดรายการ" ให้เลือกดูเป็นลิสต์แทนการปัด สำหรับผู้ใช้ที่ไม่ถนัด
- ทำป้ายบอกทิศทางบนการ์ดขณะลาก (สนใจ / ข้าม) ให้เห็นผลทันที

## รายละเอียดทางเทคนิค
- Migration เดียวสร้าง 7 ตาราง พร้อม GRANT และ RLS policy ตามหลักการข้างบน; ตารางเปิดให้ผู้ที่ไม่ล็อกอินอ่านได้เฉพาะข้อมูลสาธารณะของงาน
- `src/lib/store.ts` เปลี่ยนเป็น Supabase-backed พร้อม optimistic update และ `postgres_changes` subscription; localStorage เหลือไว้เฉพาะ session/ค่าที่เป็นของเครื่อง (savedIdeas, likedUsers, skippedUsers, consent)
- ลบไฟล์ `src/lib/demo-data.ts`, `demo-submissions.ts`, `demo-province-notes.ts` และการอ้างอิงใน `/admin/people`, `journey-data`
- โลโก้ผ่าน `lovable-assets` เป็น `.asset.json` ไม่เก็บไฟล์ไบนารีในโค้ด
