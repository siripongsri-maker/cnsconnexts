# หลังบ้านผู้ดูแล (Admin Backend) ที่ /admin

เพิ่มระบบหลังบ้านสำหรับผู้ดูแลงาน ครอบคลุมทุกเมนูที่มีบนเว็บ เข้าที่ `/admin`
ล็อกอินด้วยบัญชีผู้ดูแล (รหัสตั้งที่ env ของเซิร์ฟเวอร์ ดู `docs/ADMIN.md`)

หมายเหตุความปลอดภัย: แอปนี้เป็นโปรโตไทป์ที่เก็บข้อมูลในเครื่อง (localStorage)
รหัสผ่านนี้จึงเป็น "ประตูกั้น" สำหรับใช้ในงานเท่านั้น ไม่ใช่ระบบยืนยันตัวตนจริง
เมื่อต้องการความปลอดภัยจริง แนะนำย้ายไปใช้บัญชีผู้ใช้ + สิทธิ์ admin บนหลังบ้านจริงในเฟสถัดไป

## เฟสการทำงาน

### Phase 1 — โครงหลังบ้าน + ประตูล็อกอิน (ทำก่อน)
- `/admin` : หน้าล็อกอิน (ผู้ใช้/รหัสผ่าน) + จำสถานะไว้ในเครื่อง มีปุ่มออกจากระบบ
- โครง Admin Shell: แถบเมนูข้างซ้าย/บน รวมทุกเมนูของเว็บ
- `/admin` (หลังล็อกอิน) : ภาพรวมงาน — จำนวนสมาชิก คู่เชื่อม คำมั่นสัญญา ไอเดีย ผลงาน อัปเดตสด
- ย้าย/เชื่อมหน้าเดิมที่มีอยู่แล้วเข้าเมนูหลังบ้าน: จัดการสมาชิก (`/admin/people`), นำเข้า CSV (`/admin/import`)

### Phase 2 — จัดการเนื้อหาหลัก
- `/admin/ideas` : จัดการไอเดียในตลาดนัด (แก้ไข/ซ่อน/ลบ/เพิ่ม)
- `/admin/submissions` : จัดการผลงานที่ส่งเข้ามา (อนุมัติขึ้น e-book, แก้ไข, ลบ)
- `/admin/map` : จัดการหมุด/บันทึกรายจังหวัดบนแผนที่พลัง

### Phase 3 — จัดการความสัมพันธ์และกิจกรรม
- `/admin/connections` : ดู/แก้สถานะคู่เชื่อมทั้งหมด
- `/admin/commitments` : ดู/แก้คำมั่นสัญญา วันนัด และสถานะ RSVP
- `/admin/calendar` : มุมมองปฏิทินรวมของทั้งงาน

### Phase 4 — เครื่องมือจัดงานและรายงาน
- `/admin/live` : จอฉายกิจกรรมสด (โหมดเต็มจอสำหรับขึ้นจอในงาน)
- `/admin/qr` : สร้าง/พิมพ์ป้าย QR และรหัสห้อง
- `/admin/export` : ส่งออก CSV/JSON ทุกชุดข้อมูล + สำรอง/กู้คืนข้อมูลทั้งระบบ
- `/admin/settings` : ชื่องาน แบรนด์ ข้อความนำทาง และรีเซ็ตข้อมูลเดโม่

## รายละเอียดทางเทคนิค
- Layout ใหม่ `src/routes/admin.tsx` เป็น layout route (render `<Outlet />`) พร้อมประตูล็อกอินและเมนูหลังบ้าน
- สถานะล็อกอินเก็บที่ `localStorage` ผ่านไฟล์ใหม่ `src/lib/admin-auth.ts` (ตรวจสอบ user/password ค่าคงที่)
- หน้าย่อยทั้งหมดใช้ store เดิม (`useStore`) จึงอัปเดตข้อมูลเดียวกับฝั่งผู้ใช้ทันที
- เอกสารคู่มือผู้ดูแล + รหัสเข้าใช้ที่ `docs/ADMIN.md`

เริ่มลงมือ Phase 1 ทันทีหลังอนุมัติ แล้วค่อยทำเฟสถัดไปตามลำดับ
