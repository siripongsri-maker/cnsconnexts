# คนส. CoNnextS — "ทุ่งจับคู่" (Meadow Match) Design Spec

วันที่: 2026-10-26 · branch: `redesign/meadow-match` · สถานะ: รอเจ้าของตรวจ

## 1. เป้าหมาย

- **อ่านง่าย:** ตัวหนังสือทุกจุดผ่าน WCAG AA (4.5:1) เนื้อความ 17px ไม่มีป้ายอังกฤษตัวเล็กตกแต่ง
- **ใช้ง่าย:** สแกน QR เข้ามาแล้วเห็นการ์ดคนแรกที่ควรคุยทันทีบนหน้าแรก และกดขอเชื่อมต่อได้ภายใน 1 นาที
- **ธีม:** ตามภาพสมัชชาสุขภาพแห่งชาติ ครั้งที่ 19 "สังคม อยู่ ดี มี พลัง" (ฟ้าอ่อน ทุ่งเขียว ภูเขา กังหันลม ภาพวาดแบน)
- **Matching เป็นหัวใจ:** เมนูและหน้าแรกพาไปที่การจับคู่ก่อนอย่างอื่น

สิ่งที่เจ้าของบอก: อ่านยาก ใช้ยาก อยากได้ธีมตามภาพ เน้นการจับคู่ เลือกแบบ A "ทุ่งจับคู่" + ใช้บล็อกสีโลโก้ (แบบ C) กับแท็กประเด็น

สิ่งที่สันนิษฐาน: ผู้ใช้หลักอยู่บนมือถือในงาน หลายวัยรวมผู้สูงวัย; หลังบ้าน/ฐานข้อมูล/สูตรแมตช์ไม่เปลี่ยน

## 2. ลำดับการใช้งาน (IA)

### เมนูล่าง 4 อย่าง (`src/components/bottom-nav.tsx`)

| เมนู | ไป | รวมเส้นทางย่อย (active) | ไอคอน lucide |
| --- | --- | --- | --- |
| จับคู่ | `/` | `/`, `/matches`, `/people` | `Sparkles` |
| คู่ของฉัน | `/commitments` | `/commitments`, `/connection`, `/chat`, `/calendar` | `HeartHandshake` |
| สำรวจ | `/map` | `/map`, `/marketplace` | `Compass` |
| ฉัน | `/update` | `/update`, `/notifications`, `/dashboard` | `CircleUserRound` |

- `/matches` → redirect ไป `/` (คง query string) ลิงก์และ QR เก่าใช้ได้
- `/map` และ `/marketplace` มีแท็บสลับด้านบน "แผนที่ | ไอเดีย" (ลิงก์ระหว่างสองหน้า ไม่รวมไฟล์)
- หน้า "ฉัน" (`/update`) ด้านบนมีลิงก์: การแจ้งเตือน · สดในงาน · คู่มือ ก่อนฟอร์มแก้โปรไฟล์
- ทัวร์แนะนำ (`guided-tour`) และ `intro-guide` ไม่เปิดเอง เปิดได้จากหน้า "ฉัน"
- PDPA เหลือแถบเล็กแถบเดียวเหนือเมนูล่าง

### หน้าแรก `/` = หน้าจับคู่

```
┌────────────────────────────┐
│ [โลโก้ คนส.]        [กระดิ่ง] │  แถบหัวสีฟ้าอ่อน
│  ☁   ⛰  ✳(กังหันหมุน)  ⛰  ☁   │  MeadowScene สูง ~140px
│ ▔▔▔▔▔▔ ทุ่งหญ้า ▔▔▔▔▔▔▔▔▔ │
│ คนที่ควรเจอวันนี้   เหลือ 18 คน │  H1 + ตัวนับ
│ ┌────────────────────────┐ │
│ │ (แถบชวนทำโปรไฟล์ ถ้ายังไม่มี) │ │
│ ├────────────────────────┤ │
│ │      MatchCard ใบใหญ่     │ │
│ └────────────────────────┘ │
│  [ ✕ ข้าม ] [ ขอเชื่อมต่อ ] [ ☆ ] │  ปุ่มใหญ่ ≥ 56px
│  ↶ ย้อนการ์ดที่ข้าม              │
├────────────────────────────┤
│ จับคู่ · คู่ของฉัน · สำรวจ · ฉัน    │
└────────────────────────────┘
```

- ไม่มี SpaceNav, MissionStory, PeopleNetwork, ภาพดาวเทียม/โลก ในหน้าแรกอีกต่อไป (คอมโพเนนต์ยังอยู่ในโปรเจกต์ ไม่ลบไฟล์รอบนี้)
- ข้อมูลสถิติ (`getPublicStats`) ไม่ต้องรอใน loader หน้าแรก

### ผู้ใช้ที่ยังไม่มีโปรไฟล์

- เห็นการ์ดได้ทันที เรียงด้วย `rankForGuest(pool)` (ฟังก์ชันใหม่ใน `src/lib/matching.ts`): คนที่โปรไฟล์ครบก่อน แล้วสุ่มแบบคงที่ต่อวัน ไม่โชว์เปอร์เซ็นต์ แต่โชว์ "ทำเรื่อง … · มี …" แทน
- แถบบนการ์ด: "บอกเรื่องที่คุณสนใจ 3 ข้อ แมตช์จะแม่นขึ้น" + ปุ่ม "เริ่มเลย"
- กด "ขอเชื่อมต่อ" หรือ "เริ่มเลย" → เปิด **QuickProfileSheet** (bottom sheet, `vaul` Drawer ที่มีอยู่แล้ว) 3 ขั้น:
  1. ชื่อที่อยากให้เพื่อนเรียก + ภาค (ปุ่มภาค 6 ปุ่ม)
  2. ประเด็นที่สนใจ (บล็อกสี เลือก ≥ 1)
  3. พลังที่มี (≥ 1) และพลังที่อยากได้ (ไม่บังคับ)
  - บันทึกด้วย `saveProfile` เดิมของ store แล้วปิด sheet การ์ดจัดอันดับใหม่ด้วย `rankMatches` และถ้าเริ่มจากการกดขอเชื่อมต่อ ให้เชื่อมกับคนนั้นต่อทันที
  - ช่องอื่น (รูป องค์กร ช่วงวัย จังหวัด แนะนำตัว) แก้ทีหลังที่ `/update`
- `/onboarding` ยังใช้ได้ แต่ใช้ฟอร์ม 3 ขั้นเดียวกัน (แสดงเป็นหน้าเต็ม) แล้วพากลับ `/`

### ไอคอนพลัง (แทนอีโมจิ) — `POWER_ICON` ใน `src/lib/issue-colors.ts`

Ideas→`Lightbulb` · Community Network→`Users` · Communication→`Megaphone` · Policy Connection→`Landmark` · Funding / Resources→`HandCoins` · Knowledge→`BookOpen` · Creativity→`Palette` · Technology→`Laptop` · Partnership→`Handshake` · Local Knowledge→`MapPin`

### ตัวหนังสือ

- หัวข้อ: **Kanit** 600/700 สี `--ink` (เพิ่มใน Google Fonts link ของ `__root.tsx`; ตัด Space Grotesk/Prompt ถ้าไม่มีที่ใช้แล้ว)
- เนื้อความ: Noto Sans Thai 400/600 ขนาด 17px line-height 1.7
- ตัวเลขแมตช์: Kanit 700
- ไม่มี letter-spacing กับภาษาไทย ไม่มีป้าย uppercase ตกแต่ง

### การ์ด ปุ่ม และระยะ

- การ์ด: พื้นขาว มุม 24px เงา `0 8px 24px -12px rgba(43,40,120,.25)` ขอบ 1px `#E6E3F2`
- ปุ่มหลัก: ม่วงทึบ สูง 56px มุม 16px ตัวขาว Kanit 600; ปุ่มรอง: ขาว ขอบ `--ink` 2px
- เป้ากดทุกจุด ≥ 48px วงโฟกัสคีย์บอร์ดยังอยู่

### ฉาก MeadowScene (`src/components/meadow-scene.tsx` ใหม่)

- SVG ล้วน: ท้องฟ้า เมฆ 3 ก้อน ภูเขายอดขาวสีแดงอิฐ 2 ลูก ต้นไม้ 3–4 ต้น กังหันลม 3 ตัว ทุ่งหญ้า
- props: `variant: "header" | "celebrate" | "empty"`, `className`
- กังหันหมุนด้วย CSS (`rotate` 12s linear infinite) หยุดเมื่อ `prefers-reduced-motion`
- `aria-hidden` ไม่มีข้อความในภาพ ไม่ใส่โลโก้หน่วยงาน

## 4. การ์ดจับคู่ (`MatchCard` ใหม่ ใน `src/components/match-card.tsx` — ใช้ทั้งหน้าแรกและที่อื่น)

ลำดับบนการ์ด:

1. รูป/Avatar 72px · ชื่อ (Kanit 24px) · จังหวัด/องค์กร (16px `--ink-soft`) · วงแหวนแมตช์ 64px ขวาบน (ตัวเลขใหญ่ + คำว่า "แมตช์") — ซ่อนวงแหวนถ้ายังไม่มีโปรไฟล์
2. เหตุผล 1 ประโยค จาก `scoreMatch().reason` ในกล่องสีฟ้าอ่อน 17px
3. บล็อกสีประเด็นที่ตรงกัน (ตรงกันก่อน แล้วประเด็นอื่นของเขา รวมไม่เกิน 3)
4. สองคอลัมน์ "เขามีให้" / "เขากำลังหา" ไอคอนเส้น + ชื่อพลังไทย (สูงสุด 2 ต่อฝั่ง)
5. ลิงก์ "ดูโปรไฟล์เต็ม" → `/people/$id`

ปุ่มใต้การ์ด (`DiscoverDeck` ปรับใหม่):

- `ข้าม` (วงกลม 56px ขอบเทา, `aria-label`) · `ขอเชื่อมต่อ` (ปุ่มม่วงกว้าง) · `เก็บไว้` (วงกลม 56px ไอคอน `Bookmark`, `aria-pressed`)
- ปัดซ้าย = ข้าม, ปัดขวา = เก็บไว้ (ทางลัดเสริม ปุ่มใช้ได้เสมอ) เกณฑ์ 90px เอียงไม่เกิน 12° ปล่อยต่ำกว่าเกณฑ์เด้งกลับ
- "ย้อนการ์ดที่ข้าม" ใช้ `undoSkip` เดิม
- การ์ดหมด: MeadowScene `empty` + "คุณดูครบทุกคนแล้ว" + ปุ่ม "ดูคนที่เก็บไว้" และ "สำรวจแผนที่"

### ตอนแมตช์สำเร็จ (`MatchCelebration` ใน `src/components/match-celebration.tsx` ใหม่)

- overlay เต็มจอพื้น `--sky-soft` + MeadowScene `celebrate`
- Avatar ของเรากับเขาลอยมาจากซ้าย/ขวา มีเส้นประเชื่อม ~600ms แล้วข้อความ "เชื่อมกันแล้ว!" + ชื่อเขา + เหตุผล 1 บรรทัด
- ปุ่ม "คุยกันเลย" → `/connection/$id` และ "ไว้ทีหลัง" (ปิด, กลับการ์ดถัดไป) โฟกัสย้ายเข้า overlay, Esc ปิดได้
- reduced motion: แสดงผลสุดท้ายทันที ไม่มีการลอย

## 5. หน้าอื่นในขอบเขต

- **คู่ของฉัน (`/commitments`):** หัวข้อ "คู่ของฉัน" ส่วนบน: รายการคนที่เชื่อมแล้ว (Avatar + ชื่อ + สถานะ + ปุ่ม "คุย" / "ทำอะไรต่อ") ส่วนล่าง: คำมั่นสัญญา คงฟังก์ชันเดิม เปลี่ยนแค่โครงและสี
- **ฉัน (`/update`):** การ์ดโปรไฟล์ของฉัน (Avatar, ชื่อ, บล็อกประเด็น) + ลิงก์ด่วน 3 ปุ่ม + ฟอร์มแก้โปรไฟล์เต็ม (`ProfileForm` เดิม restyle)
- **AppShell / header:** พื้น `--sky-soft` โลโก้ซ้าย กระดิ่งขวา หัวข้อ Kanit ไม่มีป้ายอังกฤษเล็ก
- **แผนที่ ไอเดีย connection แชต สดในงาน:** ได้สีและตัวหนังสือใหม่ผ่าน token + เพิ่มแท็บ "แผนที่ | ไอเดีย" เท่านั้น ไม่จัดโครงใหม่รอบนี้

## 6. ไม่อยู่ในขอบเขต

`/admin/*`, ฐานข้อมูล/migrations, server functions, สูตร `scoreMatch`, การลบไฟล์คอมโพเนนต์อวกาศ, การจัดโครงหน้าแผนที่/ไอเดีย/แชต/สดในงานใหม่

## 7. การจัดการข้อผิดพลาดและสถานะ

- ระหว่างโหลดคนในเครือข่าย: การ์ดโครง (skeleton) 1 ใบ ไม่บล็อกทั้งหน้า
- โหลดไม่สำเร็จ: ข้อความ "ยังโหลดรายชื่อไม่ได้" + ปุ่ม "ลองอีกครั้ง" (เรียก refresh ของ store)
- บันทึกโปรไฟล์ไม่สำเร็จ: ใช้กลไก pending-sync เดิม แสดงข้อความใต้ปุ่มใน sheet ข้อมูลที่กรอกไม่หาย
- ขอเชื่อมต่อซ้ำกับคนที่เชื่อมแล้ว: ปุ่มเปลี่ยนเป็น "เชื่อมกันแล้ว · คุยต่อ"

## 8. การตรวจ

- ทำบน branch `redesign/meadow-match` ไม่ push main จนเจ้าของอนุมัติ (main sync ขึ้นเว็บจริงผ่าน Lovable)
- ห้ามสร้างข้อมูลจริงระหว่างทดสอบ: ไม่กดบันทึกโปรไฟล์/ขอเชื่อมต่อกับฐานข้อมูลจริง ส่วนที่ต้องกด ทดสอบด้วยการ stub `saveProfile`/`connect` ชั่วคราวในเครื่อง (ไม่ commit) หรือให้เจ้าของลองบน preview
- ทุกงาน: `npx tsc --noEmit -p .` + eslint ไฟล์ที่แก้ (ไม่รัน prettier ทั้งโปรเจกต์)
- ภาพหน้าจอ 375×812 และ 1440×900: หน้าแรก (มี/ไม่มีโปรไฟล์), sheet 3 ขั้น, การ์ดหมด, ตอนแมตช์สำเร็จ, คู่ของฉัน, ฉัน, แผนที่, ไอเดีย
- คอนทราสต์ทุกคู่สีตัวหนังสือ ≥ 4.5:1, reduced motion, คีย์บอร์ด/โฟกัส, ไม่มี scroll แนวนอน
- เกณฑ์สำเร็จ: จากเปิด `/` ถึงเห็นการ์ดใบแรก ไม่ต้องกดอะไร; จากการ์ดถึงขอเชื่อมต่อสำเร็จ (ไม่มีโปรไฟล์) ≤ 3 ขั้นใน sheet
