# ระบบหลังบ้านผู้ดูแล — คนส. CoNnextS

## เข้าใช้งาน
- URL: `/admin`
- ผู้ใช้: `connexts`
- รหัสผ่าน: `cns2026`

การล็อกอินเก็บสถานะไว้ในเบราว์เซอร์ (localStorage) เป็นการป้องกันระดับหน้าจอสำหรับงานเดโม่

## เมนูทั้งหมด
| เส้นทาง | หน้าที่ |
| --- | --- |
| `/admin` | ภาพรวมจำนวนสมาชิก ไอเดีย ผลงาน คู่เชื่อม |
| `/admin/people` | แก้ไขข้อมูลสมาชิก (ชื่อ องค์กร จังหวัด ประเด็น คำอธิบาย) |
| `/admin/ideas` | จัดการไอเดียใน Power Marketplace |
| `/admin/submissions` | จัดการผลงานที่ส่งเข้ามา / ตั้งค่าขึ้นโชว์ |
| `/admin/map` | ดูจังหวัดที่มีสมาชิกมากสุด และลบบันทึกรายจังหวัด |
| `/admin/connections` | ดูและปรับสถานะคู่เชื่อม |
| `/admin/commitments` | แก้ไขคำมั่นสัญญา วันนัด และสถานะ |
| `/admin/calendar` → ใช้ `/admin/commitments` | จัดการวันนัดทั้งหมด |
| `/admin/live` | จอฉายกิจกรรมสดสำหรับขึ้นโปรเจกเตอร์ |
| `/admin/qr` | สร้างรหัสห้องและ QR สำหรับติดหน้างาน |
| `/admin/import` | อัปโหลด CSV รายชื่อสมาชิก |
| `/admin/export` | ส่งออก CSV/JSON ทุกชุดข้อมูล + สำรองทั้งระบบ |
| `/admin/settings` | ข้อมูลบัญชีผู้ดูแล และรีเซ็ตข้อมูลเดโม่ |

## ข้อควรระวัง
- ข้อมูลทั้งหมดเก็บในเครื่องผู้ใช้ ไม่ได้ซิงก์ข้ามอุปกรณ์
- ปุ่ม "รีเซ็ตข้อมูลทั้งหมด" ใน `/admin/settings` ย้อนกลับไม่ได้ ควรกดส่งออกสำรองก่อน
